# Геоаналитическая карта ТЛЦ Казахстана — CALTA

## Цель проекта

Создать интерактивную геоаналитическую карту транспортно-логистических центров (ТЛЦ) Казахстана с тремя режимами отображения: обзорная карта терминальной сети, коридорно-аналитическая карта и картограмма концентрации мощностей по регионам.

## Основные возможности

### Интерактивная карта с ТЛЦ

- **Цель:** Увидеть все 58 транспортно-логистических центров Казахстана на интерактивной карте
- **Описание:** На карте Казахстана отмечены все ТЛЦ с визуальными маркерами. Карта поддерживает масштабирование и перемещение. Маркеры имеют цветовую индикацию по типу объекта (П1–П6) и размер в зависимости от мощности (TEU/год). Доступно переключение базовых карт (светлая CARTO, тёмная CARTO, OpenStreetMap).
- **Критерии приёмки:**
  - Карта Казахстана отображается с нанесёнными маркерами 58 ТЛЦ
  - Маркеры различаются по цвету (тип объекта) и размеру (мощность)
  - При наведении на маркер показывается подсказка с названием центра
  - Поддерживается масштабирование и панорамирование карты
  - Доступно переключение между тремя базовыми картами

### Типы объектов ТЛЦ

- **Цель:** Различать типы транспортно-логистических центров на карте
- **Описание:** Объекты разделены на 6 типов: П1 — Пограничные хабы, П2 — Крупные внутренние хабы, П3 — Морские порты (Каспий), П4 — КДС городские терминалы, П5 — Сеть КДС региональная, П6 — Новые объекты 2025-2026. Каждый тип имеет свой цвет маркера. Доступна легенда и фильтрация по типам.
- **Критерии приёмки:**
  - Каждый тип объекта имеет уникальный цвет маркера
  - Легенда типов отображается на карте
  - Можно фильтровать объекты по типу

### Транспортные коридоры и погранпереходы

- **Цель:** Увидеть основные транспортные коридоры и пограничные переходы на карте
- **Описание:** На карту нанесены линии транспортных коридоров: ТМТМ / Средний коридор, Паромная линия (Каспий), Северный / Транссиб, МТК Север-Юг, Западный коридор, Восточный коридор. Отмечены основные пограничные переходы (✦). Коридоры можно включать/отключать.
- **Критерии приёмки:**
  - Линии транспортных коридоров отображаются на карте
  - Каждый коридор имеет свой цвет и подпись
  - Пограничные переходы отмечены специальным символом
  - Слой коридоров можно включать и отключать

### Фильтрация по статусу

- **Цель:** Отфильтровать ТЛЦ по статусу (Действующий / Строится / Проект)
- **Описание:** Пользователь может выбрать один или несколько статусов, и на карте отобразятся только ТЛЦ выбранного статуса.
- **Критерии приёмки:**
  - Фильтр по статусу доступен в панели слоёв
  - При выборе статуса на карте остаются только ТЛЦ этого статуса
  - Можно выбрать несколько статусов одновременно

### Панель статистики (Сектор ТЛЦ КЗ)

- **Цель:** Видеть сводную статистику по всем ТЛЦ Казахстана
- **Описание:** На карте отображается информационная панель с ключевыми показателями: общее количество объектов, количество действующих / строящихся / проектных, складской фонд, мощности сектора, распределение по регионам.
- **Критерии приёмки:**
  - Панель статистики отображается на странице
  - Данные соответствуют реестру ТЛЦ
  - Панель обновляется при применении фильтров

### Детальная информация о ТЛЦ

- **Цель:** Получить подробную информацию о конкретном транспортно-логистическом центре
- **Описание:** При клике на маркер открывается попап с детальной информацией: название, тип, регион, статус, мощность, адрес, услуги.
- **Критерии приёмки:**
  - При клике на маркер открывается попап с деталями центра
  - В попапе отображаются: название, тип, регион, статус, мощность
  - Попап можно закрыть

### Три режима отображения карты

- **Цель:** Переключаться между тремя аналитическими режимами карты для отчёта
- **Описание:** В панели слоёв доступно переключение между тремя режимами:
  1. **Обзорная карта (Рис.6а):** все 58 ТЛЦ, дифференцированных по категориям П1–П6 (цвет) и статусу (форма маркера); магистральные ж/д линии, автомагистрали, погранпереходы, морские порты, паромные линии; подписи агломераций Алматы, Астаны, Шымкента и Каспийского узла.
  2. **Коридорно-аналитическая карта (Рис.6б):** транспортные коридоры (ТМТМ, Север-Юг, широтный КНР-РФ-Европа, внутренняя связность) — каждая ось своим цветом; привязка узлов — для каждого коридора видны обслуживающие его объекты реестра.
  3. **Картограмма концентрации (Рис.7а):** хороплет областей РК по доле качественных складских/терминальных площадей; контраст Алматы+Алм.обл. (~60-66%), Астана (~15-20%), Актобе (~7%) vs остальные регионы.
- **Критерии приёмки:**
  - Доступно переключение между тремя режимами
  - Каждый режим отображает соответствующие слои и данные
  - Режимы переключаются без перезагрузки страницы

### Слой плотности населения

- **Цель:** Увидеть наложение данных о плотности населения Казахстана на карту ТЛЦ
- **Описание:** На карту накладывается тепловая карта или цветовая заливка регионов по плотности населения. Слой можно включать/отключать.
- **Критерии приёмки:**
  - Слой плотности населения отображается на карте
  - Слой можно включать и отключать
  - Цветовая шкала плотности отображается в легенде

### Слой ВРП (региональный внутренний продукт)

- **Цель:** Увидеть наложение данных о ВРП регионов Казахстана на карту ТЛЦ
- **Описание:** На карту накладывается цветовая заливка регионов по уровню ВРП. Слой можно включать/отключать.
- **Критерии приёмки:**
  - Слой ВРП отображается на карте
  - Слой можно включать и отключать
  - Цветовая шкала ВРП отображается в легенде

### Зоны доступности ТЛЦ и анализ покрытия

- **Цель:** Увидеть зоны покрытия ТЛЦ (200-300 км), выявить «пустоты» (зоны спроса без обслуживания) и «дублирование» (зоны, обслуживаемые несколькими однотипными ТЛЦ)
- **Описание:** На карту накладываются круги радиусом 200-300 км вокруг каждого ТЛЦ, показывающие зону доступности. Отображаются «зоны спроса» — промзоны, крупные города и погранпереходы. С помощью анализа пересечений выявляются:
  - «Пустоты» — зоны спроса, не входящие в зоны доступности ТЛЦ (внутренние районы Мангистау и Атырау, Павлодарское и Кызылординское направления) — подсвечиваются штриховкой
  - «Дублирование» — зоны, обслуживаемые несколькими однотипными ТЛЦ (регион Алматы) — подсвечиваются особым цветом
- **Критерии приёмки:**
  - Круги доступности 200-300 км отображаются вокруг каждого ТЛЦ
  - Зоны спроса (промзоны, крупные города, погранпереходы) отмечены на карте
  - «Пустоты» визуально выделены штриховкой
  - «Дублирование» визуально выделено цветом
  - Слой можно включать/отключать

## Дополнительные заметки

- Название проекта: CALTA
- Стиль интерфейса: яркий красочный дизайн с насыщенными цветами, градиентами
- Данные о ТЛЦ — статические (58 объектов из реестра v3)
- Карта реализуется с использованием Leaflet (react-leaflet)
- Три режима отображения: обзорный, коридорно-аналитический, картограмма концентрации
- Источники: Реестр ТЛЦ v3 (KAZLOGISTICS/CALTA), Perplexity/Deepseek/Grok, 22.06.2026
- Колея КЗ: 1520 мм; стык с КНР (1435 мм) — Достык/Хоргос
